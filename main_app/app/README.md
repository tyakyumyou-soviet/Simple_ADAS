# 車載統合システムアプリ

7インチ（800×480）タッチ画面向けの統合アプリ開発版です。上部のアイコン操作、前後切替、手動イベント保存、設定・転送画面を備えます。

## 起動

```sh
cd /path/to/統合計画/main_app
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r app/requirements.txt
cp app/config.example.json app/config.json
python app/main.py --config app/config.json
```

録画・転送のRustプログラムは、それぞれの `sources` ディレクトリでビルドしてください。設定ファイルのコマンド・作業ディレクトリを環境に合わせてください。録画プログラムは `E` を手動イベント保存、`F` を安全停止の指示として受け取ります。転送開始時は録画プロセスの終了を待ってからビューアを起動し、転送を終了すると録画を再起動します。

## 設定画面

Figmaの「設定画面」案をもとに、音量、画面光量、表示カメラ（フロント／リア／OFF）、転送ソフト起動、音声変更を配置しています。800×480のタッチ画面向けに行配置へ調整しました。

- 音量はPipeWire (`wpctl`) またはPulseAudio (`pactl`) の出力先を検出した場合に操作できます。
- 光量は書き込み可能なLinuxバックライト (`/sys/class/backlight`) を検出した場合に操作できます。`brightness_file` で指定もできます。
- 表示カメラと音声言語は端末の `QSettings` に保存します。カメラ表示OFFでも録画は継続します。音声言語の警告音声への反映はAI音声出力との接続後です。
- 転送・システム停止は実行ファイルやLinux端末向け設定が使える場合だけ操作できます。転送時は録画停止の完了を確認します。
- 動画ファイルの開閉は開発用設定 `development_tools` を有効にした場合だけ表示します。

## 接続状況

- **ドラレコ:** 既存Rust録画プログラムの起動・停止と手動イベント指示を接続。
- **転送ビューア:** 既存RustビューアのWeb画面を組み込み配信へ接続。LAN用QR・セッション認証・6区分の一覧とダウンロードに対応。
- **危険予知:** 動画ファイルを既存パイプラインに流す確認機能を維持。録画カメラとのライブ共有・前後切替は未接続。
- **センサー:** ハードウェア未着のため未接続表示。
- **Wi-Fi AP:** 未接続。現在は同一LAN接続。QRとセッション認証は実装済み。
- **シャットダウン:** `allow_os_shutdown: true` の設定がある時だけ有効。

このアプリは車載運用完成版ではありません。カメラ共有、APとQR、Web認証、センサー、録画ファイルの実機確認、停止・復帰の実機確認が残っています。

## 2026-11-03: 表示とリバース、LAN転送

通常表示のフロント／リア／OFFはリバースとは独立した設定です。Rを有効にするとリア表示とリア解析指定を優先し、解除で通常表示と前方解析指定へ戻ります。解析カメラ指定はRuntimeController.analysis_cameraと接続アダプターのset_cameraへ渡します。実カメラ共有入力とADASアダプター自体は未接続です。

転送は取得済みRustビューアのWeb画面を利用し、組み込みHTTP配信から互換APIを提供します。Rustバイナリのビルド環境がないMacでも動作します。既存のRustソースは維持しています。転送時だけLANへ待受し、一時URLのQRを表示します。スマホを同じWi-Fiに接続して読み取ると、前後それぞれの通常・イベント・手動動画を一覧・再生・ダウンロードできます。読み込み中MP4はmoovヘッダー確認で除外します。配信は64KB単位で、Range要求に対応します。接続URLはセッション認証情報を含み、終了または既定15分で無効になります。録画ファイルは既存の保存先から読み、移動・再配置は行いません。

現在は同一LANでの利用です。Piのアクセスポイント化、スマホ実機接続、未完了イベント保護と録画停止の実ファイル検証は未完了です。音声変更は言語ではなくvoice_profilesに登録された音声の選択です。idとlabelを設定できます。実音声ファイルと警告音声出力への接続は未完了です。
