# Pi カメラ入力の追加調査（2026-10-30）

- Pi 5、USBカメラ CMS-V43BK、YOLO26n/Hailo-8、320×240、短時間のオフスクリーン計測。実表示とPi Connect転送は含まない。
- 指定30 FPSで、カメラ単体のV4L2受信間隔は安定後に約60 ms（約16.7 FPS）。明るい場所に向けた条件でも同程度。形式、露出、電源周波数の変更で安定後の30 FPSは得られなかった。露出と電源周波数は元に戻した。原因は未確定。
- 今回の変更前、15 Hz指定でYOLO約14.9回/秒、車線約8.5回/秒、表示側約16.3 FPS。車線を常に別フレームに延期する仕組みが制限となった。
- 実時間経路で同一フレームへの解析実行を許可。15 Hz指定の試験でYOLO・車線とも約15.2回/秒、表示側約15.5 FPS。カメラの取得速度自体は上がっていない。
- 640×360 H.264動画で同じ設定の場合、表示側約29.9 FPS、YOLO・車線とも約15.0回/秒。約20秒の試験後、温度48.3℃、throttled=0x0。
- Pi高速プロファイルのYOLOと車線の目標を各15 Hzに変更。入力低速・高負荷時は達成できない場合がある。実車条件での精度、負荷、カメラから画面までの遅延や長時間の温度は未検証。
