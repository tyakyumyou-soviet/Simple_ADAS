# 通常対象の簡略表示

2026-11-01: 通常対象とレベル1は細い枠と短いクラス名のみ表示する。
レベル2（黄色の注意）以上は従来の詳細ラベル・軌跡・矢印を維持し、通常対象より後に描画する。
同じ対象の複数警告は最も強いレベルで表示する。通常ラベル同士が重なる場合は後のラベルを省略するが、枠は残す。
検出・追跡・危険判定の対象や頻度は変更しない。

車線と設定進路の塗りつぶしは、形状と領域サイズが同じ場合にマスクを再利用する（上限16形状）。
新しい形状では再作成するため、古い車線の表示期間は延長しない。

Piの360×270の合成画像、通常対象と注意対象1件、各100回の枠・ラベル・軌跡描画比較:

| 対象数 | 変更前 中央値/95%点 ms | 変更後 中央値/95%点 ms |
| --- | --- | --- |
| 10 | 1.39 / 1.49 | 0.82 / 0.86 |
| 40 | 4.11 / 4.22 | 1.68 / 1.72 |

これは描画関数だけの単体比較で、実カメラのFPS向上や入力から表示までの遅延を測ったものではない。
注意対象が増えれば詳細描画の負荷は増える。注意以上の情報を自動で省略する機能は含まない。
