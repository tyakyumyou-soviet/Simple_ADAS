# このプロジェクトの説明（初学者向け）

むずかしい言葉はなるべく使わずに説明します。

---

## そもそも何を作るの？

一言で言うと、「**自分専用の動画ストリーミングサービス**」です。

Netflix や YouTube に似ていますが、インターネットではなく **自分の家の中だけ** で動きます。

```
イメージ図

ラズベリーパイ ─── Wi-Fi ─── スマートフォン
（動画が入ってる）           （ブラウザで見る）
```

ラズベリーパイという小さなコンピューターに動画ファイルを入れておき、スマートフォンのブラウザから「見る」「ダウンロードする」ができるようにします。

---

## なぜラズベリーパイを使うの？

ラズベリーパイは手のひらサイズの小さなコンピューターで、電気代が安く、ずっとつけっぱなしにしておくのに向いています。

- 普通のパソコン: 電気代が高い・うるさい・場所を取る
- ラズベリーパイ: 安い・静か・小さい・常時起動に最適

---

## なぜ Rust（ラスト）という言語を使うの？

プログラムを書くときに使う「言語」はたくさんあります（日本語・英語みたいなもの）。  
今回は **Rust** という言語を使います。

### 言語の比較（わかりやすく例えると）

| 言語 | スピード | 軽さ | わかりやすさ |
|---|---|---|---|
| Python（パイソン） | 普通の車 | 重め | 簡単 |
| Go（ゴー） | スポーツカー | 軽い | 普通 |
| **Rust（ラスト）** | **F1レーシングカー** | **最軽量** | 難しい |

ラズベリーパイはパワーが限られているので、最も速くて軽い **Rust** を選びました。  
「難しい」ですが、このプロジェクトでは AI が代わりに書いてくれるので問題ありません。

---

## 「親システム」って何？

このアプリは単独では動かず、**別のプログラム（親システム）に管理されます**。

```
親システム（Python で書かれたプログラム）
    │
    ├─ 「動画サーバーを起動して」→ 動画サーバー（Rust）が起動
    ├─ 「ちゃんと動いてる？」   → 「動いてます」と返事
    └─ 「もう止めていいよ」     → 動画サーバー（Rust）が停止
```

親子関係のようなイメージです。親システムが司令塔で、動画サーバーはその指示に従います。  
Python と Rust は異なる言語ですが、**「起動する」「止める」という命令はどの言語でも同じ方法で行えます**。

## 開発の流れ（4ステップ）

### ステップ1：土台作り

まず「空のサーバー」を作ります。動画は何も返せないけど、起動はできる状態。

```
ブラウザ → 「生きてる？」→ サーバー → 「生きてます！」
```

これだけできれば OK。

---

### ステップ2：サーバー機能の実装

動画フォルダをスキャンして、ブラウザからの要求に答えられるようにします。

```
ブラウザ → 「動画一覧ちょうだい」→ サーバー → 「これです！」（JSON形式）
ブラウザ → 「この動画を再生したい」→ サーバー → （動画データを少しずつ送る）
ブラウザ → 「この動画をDLしたい」→ サーバー → （ファイルを丸ごと送る）
```

この段階ではまだ見た目がなく、技術的な動作確認のみ。

---

### ステップ3：見た目の実装

スマートフォンで見やすい画面を作ります。

- 動画のグリッド一覧（インスタグラムみたいな格子状の表示）
- タップすると再生できるプレーヤー
- ダウンロードボタン
- 検索バー

---

### ステップ4：ラズベリーパイへの転送・設置

完成したプログラムをラズベリーパイに移して、電源を入れたら自動で起動するように設定します。

## 重要な用語集

| 用語 | わかりやすい説明 |
|---|---|
| **サーバー** | リクエストに答えるプログラム。飲食店の「注文を受けて料理を出す」役割 |
| **クライアント** | リクエストをするもの。飲食店の「お客さん」。今回はスマホのブラウザ |
| **API** | サーバーとクライアントの「会話ルール」。メニュー表のようなもの |
| **HTTP Range** | 動画の「ここから再生して」を実現する技術。本の特定のページを開くイメージ |
| **JSON** | データのやりとりに使う形式。「名前:値」のペアで情報を表す |
| **バイナリ** | コンピューターが直接実行できる形式のファイル。料理に例えると「完成品」 |
| **ARM64** | ラズベリーパイで使われている CPU の種類。Rust はこれに対応している |
| **SIGTERM** | 「そろそろ終了してください」というOS からプログラムへの合図 |
| **グレースフルシャットダウン** | 作業中のことを終わらせてから丁寧に終了すること。「業務終了」と「緊急停止」の違い |
