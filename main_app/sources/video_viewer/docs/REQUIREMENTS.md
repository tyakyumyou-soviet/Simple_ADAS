# 要件定義書

## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | video-viewer |
| 目的 | ローカルフォルダの動画をスマートフォンから閲覧・ダウンロードできるウェブサーバー |
| 実行環境 | Raspberry Pi 5 (ARM64, Linux) |
| 主要ユーザー | スマートフォンブラウザ（同一LAN内） |
| 親システム | Python または Rust 製プロセスマネージャーから subprocess として制御される |

---

## 2. 機能要件

### 2.1 動画一覧表示

- [ ] 指定フォルダ（およびサブフォルダ）内の動画ファイルをスキャンして一覧表示する
- [ ] 対応フォーマット: `.mp4`, `.webm`, `.mov`, `.mkv`, `.avi`
- [ ] ファイル名・更新日時・ファイルサイズを表示する
- [ ] サブフォルダを階層表示またはフラット表示で選択可能にする
- [ ] ファイル名による検索・絞り込みができる
- [ ] 更新日時・ファイル名でソートできる

### 2.2 動画再生

- [ ] ブラウザのネイティブ `<video>` タグでインライン再生する
- [ ] HTTP Range Requests に対応し、任意位置へのシークが可能である
- [ ] 再生・一時停止・音量・倍速・全画面操作ができる
- [ ] スマートフォン横持ちで全画面再生ができる

### 2.3 動画ダウンロード

- [ ] 動画ファイルをブラウザからダウンロードできる
- [ ] ダウンロード時に元のファイル名が保持される
- [ ] `Content-Disposition: attachment` ヘッダーを設定する

### 2.4 サムネイル表示（オプション）

- [ ] 動画の先頭フレームをサムネイルとして表示する
- [ ] サムネイルは初回アクセス時に生成し、キャッシュする
- [ ] ffmpeg が存在しない場合はサムネイルなしで動作する（フォールバック）

### 2.5 プロセス制御

- [ ] 起動時に設定ファイル（`config.json`）を読み込む
- [ ] SIGTERM 受信でグレースフルシャットダウンする
- [ ] 起動完了を標準出力に出力する（親システムが検知できるように）
- [ ] ヘルスチェックエンドポイント `GET /health` を提供する

---

## 3. 非機能要件

### 3.1 パフォーマンス

| 指標 | 目標値 |
|---|---|
| サーバー起動時間 | 500ms 以内 |
| 動画一覧 API レスポンス | 100ms 以内（1000ファイル以内） |
| メモリ使用量（アイドル） | 20MB 以下 |
| 同時接続数 | 5接続（家族・個人用途） |

### 3.2 互換性

- iOS Safari 15 以上
- Android Chrome 100 以上
- PC Chrome / Firefox 最新版

### 3.3 セキュリティ

- パストラバーサル攻撃を防ぐ（指定フォルダ外へのアクセスを禁止）
- LAN 内専用を前提とするため、認証はオプション（Basic Auth）
- HTTPS は任意（LAN 内 HTTP 運用を基本とする）

### 3.4 信頼性

- サーバーがクラッシュした場合、親システムが再起動できるようにする
- 動画ファイルの破損・欠落があっても他のファイルの閲覧に影響しない

---

## 4. 制約条件

- **ハードウェア**: Raspberry Pi 5（RAM 4GB または 8GB）
- **OS**: Raspberry Pi OS (64-bit, Debian Bookworm ベース)
- **ネットワーク**: 同一 LAN 内のみ（インターネット公開なし）
- **依存ソフト**: ffmpeg（サムネイル生成のみ、任意）
- **ポート**: デフォルト 8080（設定変更可能）
