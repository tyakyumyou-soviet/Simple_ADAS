# UI設計書

## 1. 設計方針

| 方針 | 内容 |
|---|---|
| ターゲット | スマートフォンブラウザ（縦持ち基本、横持ち全画面再生） |
| デザイン思想 | モバイルファースト・シンプル・タップしやすい |
| フレームワーク | なし（Vanilla HTML/CSS/JS） |
| 外部リソース | なし（フォントも CDN も使わない） |
| ダークモード | `prefers-color-scheme: dark` で自動対応 |
| アニメーション | 最小限（CSS transition のみ、JS アニメなし） |

---

## 2. 画面構成（全3画面）

アプリは **3つの画面** で構成される（SPA：ページ遷移なし、JS で表示切り替え）。

```
画面1：フォルダ選択（トップ）
  ├─ 「通常録画」をタップ
  │     ↓
  │   画面2：動画一覧（通常録画）
  │     ↓ 動画をタップ
  │   画面3：動画再生・ダウンロード
  │     ↓ 戻る
  │   画面2 → 戻る → 画面1
  │
  └─ 「イベント録画」をタップ
        ↓
      画面2：動画一覧（イベント録画）
        ↓ 動画をタップ
      画面3：動画再生・ダウンロード
```

---

## 3. 画面1：フォルダ選択（トップ画面）

アクセスした最初に表示される画面。フォルダは **2つ固定**（サーバー側で設定済み）。

### レイアウト

```
┌──────────────────────────────┐
│        録画ビューア            │  ヘッダー
├──────────────────────────────┤
│                              │
│  ┌────────────────────────┐  │
│  │ 📹 通常録画      >     │  │  ← タップでフォルダに入る
│  ├────────────────────────┤  │
│  │ ⚠️  イベント録画  >     │  │  ← タップでフォルダに入る
│  └────────────────────────┘  │
│                              │
└──────────────────────────────┘
```

### 仕様詳細

| 要素 | 仕様 |
|---|---|
| フォルダ数 | 2つ固定（「通常録画」「イベント録画」）。動的に増やさない |
| フォルダ名 | サーバー側の `config.json` で設定するパスのフォルダ名を表示 |
| 動画本数 | `/api/videos?folder=通常録画` で件数を取得して表示 |
| タップ領域 | カード全体（最低 60px 高） |

---

## 4. 画面2：動画一覧

フォルダに入ったときに表示される動画の一覧。

### レイアウト

```
┌──────────────────────────────┐
│ [← 戻る]  通常録画            │  ヘッダー（フォルダ名）
├──────────────────────────────┤
│ [サムネイル] ファイル名.mp4  ↓ │  ← ↓ はダウンロードボタン
│             1.2 GB · 12/01   │
├──────────────────────────────┤
│ [サムネイル] ファイル名2.mp4 ↓ │
│             320 MB · 11/30   │
├──────────────────────────────┤
│  ...（スクロールで続く）       │
└──────────────────────────────┘
```

### 仕様詳細

| 要素 | 仕様 |
|---|---|
| レイアウト | 1列リスト（縦スクロール） |
| サムネイル | 左側に 72×44px の小サムネイル。ffmpeg がない場合はアイコン |
| ファイル名 | そのまま表示（長い場合は末尾を `...` で省略） |
| メタ情報 | ファイルサイズ・更新日時 |
| ダウンロード | 各行の右端にダウンロードアイコン（↓）。タップで即ダウンロード開始 |
| 動画タップ | 行全体をタップ → 画面3（再生）に遷移 |
| ソート | 更新日時の新しい順（固定）。ソート切り替えは設けない |
| 戻るボタン | ヘッダー左の「←」で画面1（フォルダ選択）に戻る |

---

## 5. 画面3：動画再生・ダウンロード

動画を選択したときに表示される再生画面。

### レイアウト

```
┌──────────────────────────────┐
│ [← 戻る]  20241201_093012.mp4│  ヘッダー（ファイル名）
├──────────────────────────────┤
│                              │
│   ▶（タップで再生/一時停止）   │  動画プレーヤー（16:9）
│   ──────●────────────────   │  シークバー
│   3:28              12:34   │
├──────────────────────────────┤
│  |◀   ⏸   ▶|    ⛶         │  コントロール
├──────────────────────────────┤
│ 20241201_093012.mp4          │  ファイル情報
│ 1.2 GB · MP4 · 通常録画      │
│ [⬇ ダウンロード]              │  ダウンロードボタン（全幅）
└──────────────────────────────┘
```

### 仕様詳細

| 要素 | 仕様 |
|---|---|
| プレーヤー | HTML5 `<video>` タグ（`controls` なし、カスタムUI） |
| シーク | HTTP Range 対応により任意位置にジャンプ可能 |
| 倍速 | なし（シンプルに保つ） |
| 全画面 | コントロールバーの⛶ボタンで `requestFullscreen()` |
| ダウンロード | `<a href="/download/通常録画/ファイル名.mp4" download>` で実装 |
| 戻るボタン | 画面2（動画一覧）に戻る |
| 所属フォルダ | ファイル情報欄に「通常録画」または「イベント録画」を表示 |

## 6. カラーパレット

```css
:root {
  --bg-primary:    #ffffff;
  --bg-secondary:  #f5f5f5;
  --bg-player:     #111111;
  --text-primary:  #1a1a1a;
  --text-muted:    #888888;
  --border:        rgba(0, 0, 0, 0.12);
  --folder-normal: #e2edf5;   /* 通常録画アイコン背景（青系） */
  --folder-event:  #faeeda;   /* イベント録画アイコン背景（橙系） */
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary:    #1a1a1a;
    --bg-secondary:  #2a2a2a;
    --text-primary:  #f0f0f0;
    --text-muted:    #888888;
    --border:        rgba(255, 255, 255, 0.12);
    --folder-normal: #1a2a38;
    --folder-event:  #2e2010;
  }
}
```

「通常録画」は青系、「イベント録画」はオレンジ系で視覚的に区別する。

## 8. タップ操作の設計

| 操作 | 動作 |
|---|---|
| フォルダカードをタップ | 動画一覧（画面2）に遷移 |
| 動画リスト行をタップ | 再生（画面3）に遷移 |
| ダウンロードアイコン（↓）をタップ | ダウンロード開始（再生には遷移しない） |
| ヘッダーの「←」をタップ | 前の画面に戻る |
| 再生中の動画をタップ | 再生/一時停止 トグル |
| 横向きに回転 | 全画面表示 |

すべてのタップ領域は **最小 44×44px** を確保。

## 9. ファイル構成

```
static/
├── index.html   ← 全3画面を1ファイルに含める（display: none で切り替え）
├── style.css    ← 全スタイル・CSS変数・ダークモード
└── app.js       ← 画面切り替え・API通信・動画制御（目標 5KB 以下）
```

### `app.js` の主要関数

```javascript
init()                          // 起動時: /api/videos で動画本数を取得しトップ表示
openFolder(folder)              // 画面1→2: フォルダ名を渡して動画一覧を描画
openPlayer(folder, filename)    // 画面2→3: 動画を再生画面に表示
goBack()                        // 戻る: 画面スタックを1つ戻す
downloadVideo(folder, filename) // ダウンロードリンクを生成してクリック
```

## 10. API との対応

| 画面 | 使用するAPI |
|---|---|
| 画面1（トップ） | `GET /api/videos?folder=通常録画`（件数取得）<br>`GET /api/videos?folder=イベント録画`（件数取得） |
| 画面2（一覧） | `GET /api/videos?folder=<フォルダ名>` |
| 画面3（再生） | `GET /video/<フォルダ名>/<ファイル名>`（Range対応） |
| ダウンロード | `GET /download/<フォルダ名>/<ファイル名>` |

## 11. パフォーマンス設計

| 技法 | 理由 |
|---|---|
| 外部ライブラリ・CDN なし | ネットワーク依存ゼロ・読み込み最速 |
| `<video preload="none">` | 再生前にデータを読み込まない |
| サムネイル `loading="lazy"` | 初期表示を高速化 |
| JS 総量 5KB 以下を目標 | 転送量最小 |
| 静的ファイルをRustバイナリに内包 | ファイルI/Oゼロ |
