# Simple ADAS — 車載統合システム

Raspberry Pi向けに、ドライブレコーダー、衝突危険予知、動画転送、センサー、タッチ画面を統合する開発プロジェクトです。`ver1` は開発途中の現状を記録した版です。

## 構成

- `main_app/app/`: PySide6による統合アプリ、設定画面、LAN動画転送
- `main_app/sources/`: 危険予知、Rust録画、Rust動画ビューアの統合用ソースコピー
- `main_app/ui_preview/`: 画面案の旧プレビュー
- `対処すべき課題一覧.md`: 未完了・実機検証待ちの項目
- `統合システム仕様案.md`・`統合テストケース案.md`: 統合仕様と確認項目
- `安積プロジェクト 仮要件定義書 ver2.pdf`: 要件定義書

## 起動方法

[統合アプリのREADME](main_app/app/README.md)を参照してください。Python仮想環境、機器ごとの設定、動画データ、AIモデル、ビルド成果物は含めていません。

## 現在の状態

ラズパイの7インチ画面で表示・タッチ操作を確認し、1台のUSBカメラと既存Hailo危険予知アプリの基準計測を行いました。音量・画面光量は接続機器を検出した場合に操作できます。

前後カメラの共有、録画とAIの同時動作、センサー、AP化、イベント録画の要求適合、安全停止などは未完成または実機検証待ちです。詳細は[課題一覧](対処すべき課題一覧.md)を参照してください。

外部プログラムの出典と取得時点については[ソース一覧](main_app/sources/README.md)を参照してください。各ソースの利用条件は別途確認が必要です。
